# MetaStack Workspace

This directory stores repo-local MetaStack state generated by `metastack-cli`.

- `meta.json` stores repo-scoped defaults such as the Linear team and project ID.
- `backlog/` holds team task drafts and reusable backlog templates.
- `backlog/_TEMPLATE/` stores the repo-local backlog template used by `intu plan` and `intu backlog tech`.
- `agents/briefs/` stores deterministic kickoff prompts created by `intu agents kickoff`.
- `agents/sessions/` stores repo-local agent logs such as `intu scan`; MetaListen session state is
  stored in the install-scoped MetaStack data root keyed by the canonical source `.intuition` root.
- `codebase/` holds generated repository context for future agents.
- `cron/` stores Markdown cron jobs plus repo-local scheduler runtime state.
- `workflows/` stores repo-local workflow playbooks consumed by `intu workflows`.

Typical flow:

1. Run `intu scaffold`
2. Run `intu config`
3. Run `intu setup`
4. Run `intu scan`
5. Run `intu agents kickoff --ticket <ID>`
6. Run `intu listen`
