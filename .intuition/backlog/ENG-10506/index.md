## Context

Provide a lightweight workspace-QA loop for operators who already have a ticket workspace and
want to iterate with a headless agent without going through the full Linear/listen bootstrap path.

## Proposed Approach

- Finish the partially wired `agents build` command in `src/build.rs`.
- Reuse the shared agent-resolution and invocation pipeline with the `agents.build` route key.
- Keep continuation/session state in memory only for the lifetime of the active build loop.
- Update command help/docs and validate the command surface with focused Rust tests and clippy.

## Risks

- Risk: provider continuation support is inconsistent.
- Mitigation: Codex resumes the same build session when a continuation handle is available; other
  providers queue follow-up input for the next loop iteration with an explicit note.
