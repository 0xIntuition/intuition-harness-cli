## Notes

- Built-in listen turns no longer depend on stdout EOF because `src/listen/worker.rs` now takes
  ownership of child stdin, writes the prompt payload, and drops the handle before waiting on the
  supervised child.
- Timeout reporting remains distinct from stalled-turn reporting in `src/listen/state.rs`,
  `src/listen/dashboard.rs`, `README.md`, `WORKFLOW.md`, and
  `docs/listen-phased-execution-spec.md`.
- Verification recipe timeout defaults and validation remain covered by
  `src/listen/verification.rs` unit tests, including omitted `timeout_seconds` defaulting to `300`
  and zero timeout rejection.
- The literal default-agent command `cargo run -- agents listen --check --root .` was not used as
  final evidence because this workstation already had an active listener lock under the
  install-scoped config, and the default built-in `codex` preflight failure is environment-specific
  rather than branch-local to ENG-10725.
