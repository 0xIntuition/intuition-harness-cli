## Summary

Repo-level reviewer evidence for ENG-10732: add bounded post-publication GitHub CI settle polling
to `meta listen`, including install-scoped config defaults, structured `gh pr checks` snapshots,
same-PR repair reuse, and reviewer-visible wait/timeout/no-checks surfaces.
