# ENG-10816 Validation Evidence

## Summary

`meta backlog improve` now uses the same scoped terminal-cleanup pattern as the
other shared TUI flows: callers explicitly enter the interactive or loading
terminal, keep a tiny drop guard in scope, and drop the active terminal/display
before printing shell-facing output. The refactor removes
`ImprovementTerminalSession` and stops `ImprovementLoadingDisplay` from owning
cleanup directly, while preserving `Ctrl+G` mouse toggling, non-TTY loading
behavior, and the existing backlog-improve review flow.

The regression coverage now proves the exact restore ordering:
cursor restore, then `DisableBracketedPaste`, `DisableMouseCapture`, and
`LeaveAlternateScreen`. It also adds a PTY-backed cancel-path proof showing that
the issue-picker escape path restores terminal state before printing
`Backlog improvement cancelled.`.
