## Acceptance Criteria Mapping

- `src/listen/state.rs` now keeps `SessionPhase` as the last reached phase while introducing
  additive `SessionLifecycleOutcome`, `SessionExitCondition`, and derived lifecycle helpers so the
  store and UI can distinguish clean completion from truncated or resumable exits.
- `src/listen/store.rs` now retains lifecycle-bearing audit history under
  `listen/projects/<PROJECT_KEY>/audit/`, preserves it across TTL pruning and cleanup, and keeps
  retained session detail visible after live records are cleared.
- `src/listen/mod.rs` now merges live and retained session summaries for list, inspect, and
  dashboard flows, preserves lifecycle-aware reconciliation decisions, and keeps resumable
  truncated sessions visible to the existing resume paths.
- `src/listen/dashboard.rs` now renders `PHASE`, `STATE`, and `EXIT` columns plus lifecycle and
  exit detail in the selected-session pane so operators can inspect incomplete lifecycles without
  falling back to raw logs.
- `src/listen/worker.rs` now records publishing-phase completions and truncated handoff exits using
  lifecycle metadata, keeps timeout review guidance distinct from stalled-turn handling, and logs
  structured timeout metadata including the graceful-shutdown window and final termination path.
- `tests/listen.rs` now covers retained audit visibility, lifecycle-aware inspect output, clean and
  truncated publishing exits, deterministic dashboard surfaces, and the dedicated timeout and
  stubborn-timeout proofs listed above.
- `README.md`, `docs/agent-daemon.md`, `docs/listen-phased-execution-spec.md`, and `WORKFLOW.md`
  now document retained audit visibility, phase-vs-lifecycle semantics, and the timeout contract
  that keeps subprocess timeouts distinct from stalled-turn detection.
