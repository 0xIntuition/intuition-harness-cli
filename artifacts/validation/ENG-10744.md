# ENG-10744 Validation Evidence

## Summary

Repo-level reviewer evidence for ENG-10744: listen reconciliation now classifies dead stored worker
PIDs, automatically relaunches retryable listen-origin running sessions from persisted context with
a fixed `2`-attempt budget, persists recovery metadata before spawning the replacement worker so
the worker cannot erase it with an early session write, and preserves additive stale-worker
metadata across session JSON, mirrored detail JSON, inspect output, and dashboard selected-session
detail rendering. The current tree also routes paused sessions with a stored dead PID through the
same stale-worker classifier so they terminate as structured `blocked` sessions instead of being
silently skipped during reconciliation. The full local reruns below completed on 2026-04-09 from
workspace head `8643494`, and this file is the authoritative reviewer checkpoint for that tree.
