# ENG-10782 Validation Evidence

## Summary

Repo-level reviewer evidence for ENG-10782: listen now resolves one
configurable context budget across CLI, repo, install, and built-in defaults;
workers derive context pressure from completed-turn known input tokens only;
high and critical pressure trigger durable checkpoint behavior against the
effective workpad body; and the selected-session detail pane renders live
context pressure without adding a new persisted session field or table column.

The final validation pass also repaired the continuation-turn regression that
surfaced during this run: after adding the `Context Pressure` detail field, the
execute-origin operator note fell below the render-once fold in the dashboard
detail pane. `src/listen/dashboard.rs` now renders that execute-origin note
immediately after the summary fields so the render-once contract remains
visible.

## Acceptance Criteria Mapping

- `src/config.rs`, `src/config_command.rs`, `src/setup.rs`, `src/cli.rs`, and
  `src/listen/mod.rs` implement the requested context-budget precedence and
  propagate the resolved numeric budget into every hidden worker launch path.
- `src/listen/state.rs` derives `ContextPressure` from completed-turn known
  input tokens only and keeps the pressure state computed rather than persisted.
- `src/listen/workpad.rs` and `src/listen/worker.rs` use the effective workpad
  body (`pending_linear_sync.workpad_body` first, active Linear workpad second)
  for checkpoint detection, checkpoint preservation, and later review-workpad
  rewrites.
- `src/listen/worker.rs` limits only remaining execution turns under `critical`
  pressure, preserves one-time checkpointing, and keeps timeout handling
  distinct from repeated no-progress stall handling.
- `src/listen/dashboard.rs` renders `Context Pressure` only in the selected
  session detail pane and keeps the execute-origin render-once operator note
  visible after the new field addition.
- `README.md`, `WORKFLOW.md`, `docs/agent-daemon.md`, and
  `docs/listen-phased-execution-spec.md` document the new context-budget and
  pressure/checkpoint behavior in the same change.
