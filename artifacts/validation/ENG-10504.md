# ENG-10504 Validation Evidence

## Summary

Repo-level reviewer evidence for ENG-10504: the CLI now computes one shared workspace-pressure
summary with disk and memory state plus the total managed-workspace footprint, `meta agents listen
--check` reports that summary, unattended listen startup blocks on `critical` pressure before
claiming work or launching a worker, and listen/workspace surfaces reuse the same pressure and
cleanup guidance text. Listener reconciliation also now removes safe completed workspaces after a
later PR merge while still preserving dirty, ahead, detached, and otherwise unsafe workspaces with
clear reasons. While finishing the feature work, a real regression surfaced in the listen session
merge path: equal-second `updated_at_epoch_seconds` values could drop summary-only reconciliation
updates. That regression is fixed and covered by a dedicated test.
